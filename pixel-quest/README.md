# Pixel Quest — Science Adventure

A browser-based educational pixel-art game built with HTML Canvas and vanilla JavaScript.

## Play
Open `index.html` in a modern browser. No build tools, package installation, or server are required.

## Controls
- **A / D** or **← / →** — move
- **Space / ↑** — jump
- **E** — interact with a nearby science station
- **Esc** — field guide

## Learning stations
1. Solar energy and Earth's climate
2. Atomic particles and electric charge
3. Cell structures
4. Gravity
5. The chemical formula of water

Correct answers award 100 XP. Explanations are shown after each answer.

## Technology
- HTML5 Canvas 2D
- Vanilla JavaScript
- CSS
- No external game engine or runtime dependencies

This is a self-contained browser game.
